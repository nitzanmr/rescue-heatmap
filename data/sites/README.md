# data/sites

שכבות GeoJSON של אתרי נעדרים (מוקדי דיווח), לטעינה כשכבה במפה.

- `mahe-sites-2026-08-13.geojson` — 17 אתרים בקאלי / פררה-דוסקברדס / קיבדו / קימבאיה.
  ספירות `people_est` = אנשים מובחנים אחרי דדופ, מקור colombiatebusca 2026-08-13 (מהימנות C).
  `precision` מציין את רמת הדיוק: `building` (±25–200מ') מול `barrio` (מרכז מנהלי, ±1500מ') —
  נקודת barrio אינה מבנה ואין לנווט אליה.
  שני אתרים (El Remanso, María Elvira) חסרים נקודה ודורשים נעיצה ידנית.

אין בקבצים האלה מידע אישי — שמות, טלפונים או כתובות של נעדרים.
