# Emergency Contacts Database

## How to Use

This directory contains contact lists for disaster response distribution, organized by region.

Each file should follow this format:

```markdown
# [Country/Region] Contacts

## Local Media
| Name | Outlet | Type | Contact | Language | Last Verified |
|------|--------|------|---------|----------|---------------|

## Community Groups (WhatsApp/Telegram)
| Group Name | Platform | Members | Region | Link/Admin Contact | Last Verified |
|------------|----------|---------|--------|-------------------|---------------|

## Government / Emergency Management
| Agency | Contact Person | Role | Phone/Email | Last Verified |
|--------|---------------|------|-------------|---------------|

## NGOs / International Organizations
| Organization | Contact Person | Role | Phone/Email | Last Verified |
|-------------|---------------|------|-------------|---------------|

## Influencers / Community Leaders
| Name | Platform | Followers | Region | Handle | Last Verified |
|------|----------|-----------|--------|--------|---------------|
```

## ⚠️ Privacy Note

Contact details in this directory are for disaster response coordination only. Do not share publicly. Consider keeping this directory in a private fork if the repo is public.
