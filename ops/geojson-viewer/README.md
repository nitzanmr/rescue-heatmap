# מציג GeoJSON מקומי — צוות מא"ה

ממשק ווב קטן לצפייה בקבצי ה-GeoJSON שאנחנו מייצרים, בלי QGIS ובלי להעלות
שום דבר לענן. רץ מקומית, קורא את `data/` **לקריאה בלבד**.

## הרצה עם דוקר (מומלץ)

```bash
cd rescue-heatmap/ops/geojson-viewer
docker compose up -d --build
```

פותחים: http://localhost:8899

עצירה: `docker compose down`
פורט אחר: `VIEWER_PORT=9000 docker compose up -d`

## הרצה בלי דוקר

```bash
cd rescue-heatmap/ops/geojson-viewer
python3 server.py            # ברירת מחדל: פורט 8899, data/ של הריפו
PORT=9000 DATA_DIR=/some/dir python3 server.py
```

אין תלויות — ספריית התקן של פייתון בלבד. Leaflet ו-markercluster
יושבים ב-`vendor/` ונטענים מקומית, כך שהממשק עובד גם בלי אינטרנט
(האריחים של OSM כן דורשים רשת).

## מה יש בממשק

- **בחירת קובץ** — כל `*.geojson` תחת `data/` מופיע ברשימה אוטומטית.
- **גרירת קובץ** אל המפה, או בחירה מהדיסק — לצפייה בקובץ שלא בריפו.
- **שכבות לפי סוג** (`kind`): רפואי, בית מרקחת, דלק, סופר, מקלט,
  מועמד למקלט, כוח הצלה — עם ספירה וכיבוי/הדלקה.
- **חיפוש חופשי** על כל שדות המאפיינים.
- **קליק על נקודה** → שם, סוג, כתובת/טלפון אם יש, ולינק לאובייקט ב-OSM.
- אשכולות (clustering) עד זום 16, כדי ש-2,249 נקודות לא יתקעו את הדפדפן.

## שיתוף עם אחרים

הפורט פתוח על `0.0.0.0` בתוך הקונטיינר, כך שמי שברשת המקומית יכול
לגשת ב-`http://<ip-שלך>:8899`. דרך tailscale — אותו דבר עם כתובת ה-tailnet.
**אין אימות ואין הצפנה** — לא לחשוף לאינטרנט הפתוח.

## אזהרה על התוכן

הנקודות מגיעות מ-OpenStreetMap (רישיון ODbL). OSM אומר שנקודה **קיימת**,
לא שהיא **פועלת**. אחרי רעידת אדמה — לאמת לפני נסיעה.
